# FlavorHunt – Test Cases

This document maps directly to the automated `Vitest` + `Supertest` backend API test suite implemented in `tests/auth.test.js`, `tests/middleware.test.js`, and `tests/recipes.test.js`.

| Test Case ID | Test Case Name | Module | Test Scenario | Preconditions | Test Input / Test Data | Expected Result | Actual Result | Status |
|---|---|---|---|---|---|---|---|---|

| **FH-TC-008** | Missing Authorization Header | Auth Middleware | Verify `authMiddleware` blocks protected routes when no `Authorization` header is sent. | Protected route `GET /api/recipes/saved`. | Request with no `Authorization` header. | HTTP `401`, JSON `{"message": "No token, authorization denied"}`. | Returned HTTP `401` with `{"message": "No token, authorization denied"}`. | **PASS** |
| **FH-TC-009** | Malformed Authorization Header | Auth Middleware | Verify `authMiddleware` blocks tokens that do not use the `Bearer ` prefix. | Protected route `GET /api/recipes/saved`; valid JWT signed. | Header `Authorization: Token <jwt>` | HTTP `401`, JSON `{"message": "No token, authorization denied"}`. | Returned HTTP `401` with `{"message": "No token, authorization denied"}`. | **PASS** |
| **FH-TC-010** | Invalid or Expired JWT Token | Auth Middleware | Verify `authMiddleware` rejects malformed and expired Bearer tokens. | Protected route `GET /api/recipes/saved`. | (1) `Bearer malformed.jwt.token`; (2) `Bearer <expired_jwt>` (`expiresIn: -10`) | HTTP `401`, JSON `{"message": "Token is not valid"}` for both cases. | Both invalid and expired tokens returned HTTP `401` with `{"message": "Token is not valid"}`. | **PASS** |
